## Don Quixote <br> A simple Project Directory Manager
  Project Pointer
  Directory Pointer
  Project Directory Manager
  Project Manager
  Directory Manager

- A useful workaround to monotonous keystrokes and 'cd's
- Call on 'quixote' to see remind yourself of your latest projects
- New project? Tell quixote to 'summon project_name' to save the directory under a name
- Know which specific project you'll take on? Type 'quixote project_name' to be redirected immediately

## A Terminal and quixote Go Hand in Hand
  Terminals always open a few folders away from your projects.
  'quixote' allows you to be only one command away from diving into work

## Why Name it "Don Quixote"?
  I'm a fan of the book, it's a lot of fun!
  It's nice for projects to have names.
